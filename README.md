# עולם הניקוד 🎈

אתר בקובץ HTML בודד ללימוד סימני הניקוד בעברית, מותאם לילדים קטנים.

## מה יש באתר?

- **דף לימוד** — כל סימני הניקוד עם השם, הצליל, וסימון האם זו תנועה גדולה, תנועה קטנה או סימן מיוחד (שווא וחטפים).
- **כפתור השמעה** 🔊 ליד כל סימן — לחיצה משמיעה את שם הסימן ואת הצליל שלו (באמצעות הקראה קולית של הדפדפן).
- **מבחן אמריקאי** 🏆 — 10 שאלות שמוגרלות מחדש בכל פעם, עם משוב מיידי, ציון בסוף, כוכבים וקונפטי.

## איך משתמשים?

פותחים את הקובץ `nikud-learning.html` בדפדפן — זהו, אין צורך בהתקנה או שרת.

> 💡 להשמעת הקול מומלץ דפדפן Chrome (במחשב או בטלפון), שכולל קול עברי מובנה.
