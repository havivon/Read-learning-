# סימני הניקוד — מדריך ותרגול

אתר בקובץ HTML בודד ללימוד סימני הניקוד בעברית, בעיצוב נקי המתאים למבוגרים.

## מה יש באתר?

- **דף לימוד** — כל סימני הניקוד עם השם, הצליל, וסימון האם זו תנועה גדולה, תנועה קטנה (כולל קמץ קטן) או סימן מיוחד, עם הסבר על ההבדל בין שווא נע לשווא נח.
- **כפתור השמעה** 🔊 ליד כל סימן — לחיצה משמיעה את שם הסימן ואת הצליל שלו (באמצעות הקראה קולית של הדפדפן).
- **מבחן אמריקאי** — 10 שאלות שמוגרלות מחדש בכל פעם, עם משוב מיידי, הצגת התשובה הנכונה לאחר טעות, וציון מסכם.

## איך משתמשים?

פותחים את הקובץ `nikud-learning.html` בדפדפן — זהו, אין צורך בהתקנה או שרת.

> 💡 להשמעת הקול מומלץ דפדפן Chrome (במחשב או בטלפון), שכולל קול עברי מובנה.
